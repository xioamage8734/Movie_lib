电影库 · 使用说明
============================================================

一个本地的电影管理工具：
扫描你硬盘上的电影 → 自动去豆瓣抓评分 / 海报 / 简介 → 网页海报墙
可以筛选、搜索、一键播放、手动修正，手机 / 电视连同一个 WiFi 也能看。


【第 1 步】装 Node.js（只需一次）
------------------------------------------------------------
打开  https://nodejs.org   下载 LTS 版，一路「下一步」装完。

★ 装完请【新开一个窗口】再继续（双击 bat 也一样）。


【第 2 步】启动
------------------------------------------------------------
双击  【启动.bat】

  · 会弹出一个黑色窗口 —— 别关它，关了程序就停了
  · 浏览器会自动打开  http://localhost:7777
  · 如果没自动打开，就手动在浏览器里输这个地址


【第 3 步】配置（全部在网页里做，只需一次）
------------------------------------------------------------
刚打开时页面上会显示「片库还是空的」，照下面走：

  1. 点左下角的  「⚙ 管理电影目录」（页面中间也有一个大按钮）
  2. 点「＋ 添加一个目录」，填你的电影根目录
       例如   D:\电影      或   E:/Movies
     一行一个，可以加多个目录。
     路径里用 \ 或 / 都行 —— 直接从资源管理器地址栏复制粘贴即可；
     也可以点旁边的「浏览…」，在里面点进点出选一个目录，不用自己打路径。
  3. 点  「📥 抓取资料」

就这三步。点完之后程序会自动依次做完：

    ① 保存你填的目录
    ② 扫描这些目录，找出里面的视频文件（这步很快）
    ③ 去豆瓣抓海报、评分、简介（这步要几十分钟）

  · 第 ② 步一结束，关掉弹窗就能看到自己的片子列表了（还没有海报）
  · 抓到的资料会一条一条往上补
  · 面板上会实时显示当前进行到哪一步
  · 抓取随时可以关掉窗口，进度会保存，下次接着跑
  · 如果一直没进展，多半是被豆瓣限流了，过几小时再点一次就行


【手机 / 电视上看】
------------------------------------------------------------
  1. 手机 / 电视连【同一个 WiFi】
  2. 第一次启动时 Windows 防火墙会弹窗
       → 选「允许访问」，并勾上「专用网络」
  3. 用黑色窗口里打印的那个地址，形如  http://192.168.x.x:7777
       ★ 注意不是 localhost
  4. 点海报右下角那个小 ▶ 播放

  ★【重要】手机 / 电视上请先装一个视频播放器：VLC
     应用商店搜「VLC」装上就行。
     不装的话，.mkv / H.265 这类片子在浏览器里放不出来
     —— 这是浏览器的能力限制，换哪个浏览器都一样。

  ★ 手机 / 电视上是「只看片」模式：添加目录、扫描、抓取资料、删除
     这些入口不显示（免得误点），都需要在这台电脑上操作。
     筛选、搜索、看详情、播放都正常。

  ★ 点 ▶ 时会自动判断「该用哪台设备播放」：
     凡是通过 http://192.168.x.x:7777 打开的，都算「别的设备」，
     于是去唤起这台设备上的播放器。
     万一判断反了（比如电视上点了、结果电脑开始放），
     在左边栏最底下的「点 ▶ 时」里手动改一下，改完会记住。


【播放说明】
------------------------------------------------------------
  电脑上点 ▶  →  用电脑上的播放器打开
  手机上点 ▶  →  唤起手机上的播放器（VLC）

  如果没弹出播放器，播放层里会出现这些按钮：
      · 「外部播放器」  →  再试一次唤起手机上的播放器
      · 「复制链接」    →  把链接手动粘进 VLC 播放

  有些 mp4 格式浏览器能直接放，就会在网页里播了。


【日常使用】
------------------------------------------------------------
  · 左边筛选：评分、类型、国家、年份、片长、状态
  · 顶上搜索：片名 / 英文名 / 导演 / 主演
  · 点海报 → 看详情（简介、导演、主演、所有版本、文件路径）
  · 点海报右下角的小 ▶ → 播放


【片名对不上怎么办（手动搜索）】
------------------------------------------------------------
  下载站的文件名经常很乱 —— 比如「pdy」「XUNLONG」这种拼音缩写，
  或者「战栗1978」把年份写错了。程序可能搜不到、或者搜错。

  修法：
    点开那部片的详情 → 点「手动搜索豆瓣条目」
    → 输入正确的片名 → 在结果里选中对的那部 → 绑定

  ★ 选错了怎么办？
    已经匹配过的片子，详情页上会有一个「重新匹配豆瓣条目」按钮。
    点进去能看到「当前匹配：xxx」，直接在下面重新选一个绑上去就行，
    覆盖掉旧的不影响。

  绑定过的片子，程序以后不会再自动改动它。


【整理片库】
------------------------------------------------------------
  都在「⚙ 管理电影目录」面板里，往下滚：

  · 修正错配
      重新匹配那些「疑似配错」的片子（关掉弹窗后它会自己重跑）。
      你手动绑定过的不会被动到。

  · 同一部片的多条记录
      同一部电影出现了两条（比如 4K 版和 1080p 版因为目录名不同、
      扫描时没认出是同一部），可以合并成一条 ——
      合并后列表只显示一条，各个文件在详情页里都能看到，不会删文件。
      ★ 如果它提示「本地年份不一样」，那多半是配错了、不是重复，别合并。

  · 查找重复文件
      同一部片留了多个文件时会列出来，可以清理掉多余的。

  · 删除电影
      在任意一部片的详情页，点底部的「删除这部电影」就行。
      如果这部片有多个版本（比如 4K 和 1080p 各一个文件），
      每个文件右边还会多一个 🗑，可以只删掉其中某一个版本。
      ★ 删掉的文件会先挪到同盘的 _movie-lib_deleted 文件夹里，
        不是真删除，随时能用资源管理器拷回来。

  · 清空回收区
      想真正释放硬盘空间，才点这个 —— 它会把 _movie-lib_deleted
      里攒着的东西彻底删掉，不可恢复。
      面板上会显示回收区现在占了多少空间。


【文件都是干什么的】
------------------------------------------------------------
  启动.bat      打开网页海报墙（日常就双击这一个）
  config.json   配置：电影目录、端口等（不用手改）
  data\         数据目录：片库数据 + 海报缓存
  src\          程序源码（不用动）
  public\       网页界面（不用动）


【常见问题】
------------------------------------------------------------
Q: 提示 "node 不是内部或外部命令"
A: 没装 Node.js，或者装完没重开窗口。装完后新开一个窗口再试。

Q: 双击 bat 一闪而过 / 没反应
A: 先开一个 cmd 窗口，把 启动.bat 拖进去回车，就能看到具体错误。
   ★ 千万不要双击 src 里的 .js 文件 —— 那是源码。

Q: 手机连不上
A: 1) 手机和电脑必须连同一个 WiFi
   2) 首次启动时防火墙弹窗要选「允许访问」并勾「专用网络」
   3) 用黑色窗口里那个 http://192.168.x.x:7777（不是 localhost）

Q: 手机上点播放没反应 / 没弹出播放器
A: 装 VLC。装完之后在播放层点「外部播放器」，或者直接点「用 VLC 打开」。
   还不行就点「复制链接」，把链接粘进 VLC 打开。

Q: 抓取时一大堆 unmatched，或者很久没进展
A: 豆瓣把你的 IP 限流了。关掉抓取，等几小时再重开；
   程序会自动退避，隔得越久越容易恢复。
   另外，文件名是拼音缩写的那种片子本来就搜不到，需要手动绑定。

Q: 扫描完了，但页面上还没有海报和评分
A: 正常。扫描只负责找出片子，海报和评分靠后面那步「抓取资料」。
   可能是还没抓完，或者被豆瓣限流卡住了。

Q: 删掉的片子还在列表里没消失
A: 再点一次它的 🗑（会提示「文件已不在，只清理了片库记录」），
   或者在管理面板里点「仅扫描」刷新一下片库。

Q: 想换电影目录 / 硬盘里加了新片子
A: 再进「⚙ 管理电影目录」，改好目录（或加一行），点「📥 抓取资料」——
   已抓过的会自动跳过，只补新的。
   只想刷新片子列表、不想抓资料的话，点「仅扫描」即可。
