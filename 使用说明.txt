电影库 · 使用说明
============================================================

一个本地的电影管理工具：扫描你的硬盘 → 抓豆瓣资料 → 网页海报墙
可以筛选、看简介、一键播放，手机 / 电视也能访问。


【第一次使用】三步
------------------------------------------------------------

第 0 步：装 Node.js（只需一次）
    打开 https://nodejs.org  下载 LTS 版，一路「下一步」装完。
    ★ 装完必须【新开一个命令行窗口】才能识别，双击 bat 也建议重开。

第 1 步：配置电影目录
    双击  【配置向导.bat】
    - 它会问你电影放在哪，一行填一个目录，填完直接回车
    - 可以把文件夹【直接拖进黑色窗口】，路径会自动填好
    - 填完它会自动扫描一遍，告诉你找到多少部片子

第 2 步：抓取资料（海报 / 评分 / 简介）
    双击  【抓取.bat】
    - 首次视片子数量，约 30~60 分钟
    - 可以随时关掉窗口，进度会保存，下次接着跑
    - 如果显示"豆瓣限流"，让它自己等就行（会自动重试）

第 3 步：打开海报墙
    双击  【启动.bat】
    - 浏览器会自动打开 http://localhost:7777
    - 窗口里还会显示局域网地址，手机 / 电视连同一个 WiFi 就能访问


【日常使用】
------------------------------------------------------------
  · 左边筛选：评分、类型、国家、年份、片长、状态
  · 顶上搜索：片名 / 英文名 / 导演 / 主演
  · 鼠标移到海报上会出现 ▶，点一下直接播放
  · 点海报进详情：简介、导演、主演、所有版本、文件路径

  播放规则（只判断你在哪台设备上点）：
    电脑上点 ▶  →  用电脑上的播放器打开
    手机上点 ▶  →  唤起手机上的播放器（选一次 VLC 之类即可）


【文件都是干什么的】
------------------------------------------------------------
  配置向导.bat    首次配置 / 之后想改目录时再双击
  抓取.bat        抓豆瓣资料（可反复运行，只补缺的）
  启动.bat        打开网页海报墙
  config.json     配置文件：电影目录、端口、播放器路径
  data/           数据目录：library.json（片库）、posters/（海报缓存）
  src/            程序源码（不用动）


【常见问题】
------------------------------------------------------------
Q: 提示 "node 不是内部或外部命令"
A: 没装 Node.js，或者装完没重开窗口。装完后请新开一个窗口再试。

Q: 双击 bat 没反应 / 一闪而过
A: 用右键 →「以管理员身份运行」；或先开一个 cmd 窗口，把 bat 拖进去回车。
   ★ 千万不要去双击 src 目录里的 .js 文件——那是源码，会被 Windows 用错程序打开。

Q: 手机连不上
A: 1) 手机必须和电脑连同一个 WiFi
   2) 首次启动时 Windows 防火墙弹窗，要选「允许访问」，并勾选「专用网络」
   3) 用窗口里打印的那个 http://192.168.x.x:7777 地址（不是 localhost）

Q: 抓取时一大堆 unmatched
A: 多半是豆瓣把 IP 限流了。关掉抓取窗口，等几小时再跑；
   程序有自动退避，隔得越久越容易恢复。

Q: 手机点播放没反应
A: 手机需要装一个视频播放器（推荐 VLC）。第一次点会弹「打开方式」，
   选 VLC 并勾选「始终」，以后就一键直连了。

Q: 想换电影目录
A: 再双击一次【配置向导.bat】，重新填写即可（会覆盖旧列表）。


【把这套东西分享给别人】
------------------------------------------------------------
  1. 把整个 movie-lib 文件夹复制给对方
  2. 删掉里面的 data 文件夹（那是你的片库数据）和 config.json（你的路径）
  3. 对方装好 Node.js 后，双击【配置向导.bat】配自己的目录即可
